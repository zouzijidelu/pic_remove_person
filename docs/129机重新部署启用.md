## 0. 部署前再确认 GPU

```bash
sudo -i

```

必须：`nvidia-smi` 能看到 L20；`lspci` 有 `10de`；磁盘空余足够（本机约 230G，够用）。**不要**在认不到卡时重装驱动。

## 2. 部署 Demo（LaMa + SAM）

```bash
export HF_ENDPOINT=https://hf-mirror.com
cd /root/pano-inpaint
chmod +x deploy_server.sh setup.sh start.sh
bash deploy_server.sh
```

若报 `pyenv: python3.12: command not found`（shim 存在但未指向具体版本），指定真实解释器：

```bash
export PYTHON_BIN=/root/.pyenv/versions/3.12.11/bin/python
"$PYTHON_BIN" --version
SKIP_APT=1 bash deploy_server.sh
```

路径不对就 `ls /root/.pyenv/versions/3.12.*/bin/python` 换成实际文件。不要用名为 `deepseek` / `da-2` 的现成环境。

脚本会：建 Python 3.12 venv、装 CUDA torch、写 `server.env`、注册 systemd **`pano-lama`**、监听 **7860**。

```bash
journalctl -u pano-lama -f
```

等到 `Running on` / `[warmup] 完成`。浏览器：`http://10.2.143.129:7860`。先只用 **LaMa** 消一张，确认 GPU 正常。

## 3. 加 PowerPaint

```bash
cd /root/pano-inpaint
bash deploy_powerpaint.sh
```

要求 `/root/iopaint-bench/inpaint_worker.py` 已在。PowerPaint 用 **Python 3.11** 旁路 venv（不要用 Demo 的 3.12）。没有 3.11 时脚本会落到 3.12，`iopaint` 可能从 **pypi.org 再下一份 torch（500MB+）**，几十 kB/s 会卡一个多小时。

若已经很慢（正在下 `torch-2.13.0`），**Ctrl+C**，改成先装 CUDA torch、再装 iopaint：

```bash
# 优先 3.11；没有再用 3.12 的真实路径，不要 pyenv 的 python3.12 shim
export PYTHON=/usr/bin/python3.11
# 或：export PYTHON=/root/.pyenv/versions/3.12.11/bin/python

cd /root/iopaint-bench
rm -rf .venv
"$PYTHON" -m venv .venv
.venv/bin/python -m pip install -U pip -i https://pypi.tuna.tsinghua.edu.cn/simple
.venv/bin/python -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cu124
# 上面也慢则改：--index-url https://mirrors.aliyun.com/pytorch-wheels/cu124/

.venv/bin/python -m pip install "iopaint==1.6.0" \
  -i https://pypi.tuna.tsinghua.edu.cn/simple \
  --extra-index-url https://pypi.org/simple

.venv/bin/python -c "import torch, iopaint; print(torch.__version__, torch.cuda.is_available())"

cd /root/pano-inpaint
SKIP_SETUP=1 bash deploy_powerpaint.sh
```

`SKIP_SETUP=1` 只写 `server.env` 并重启服务，不再重装依赖。

`server.env` 会被写成：

```
ENABLE_POWERPAINT=1
POWERPAINT_DEVICE=cuda
POWERPAINT_MAX_SIDE=768
IOPAINT_BENCH=/root/iopaint-bench
```

界面出现 PowerPaint 后，**第一次点才会加载约 4GB**（若未预热），约 1～2 分钟，之后进程常驻会快很多。

### 若 journalctl 出现 `the: command not found`（exit 127 循环）

PowerPaint 的 `.venv` 已经装好了，**不是依赖问题**。`start.sh` 会加载 `server.env`；`QWEN_EDIT_PROMPT` 里有空格且没加引号时，bash 把 `the` 当成命令，服务立刻退出。

在 129 上立刻修（不必等 git pull）：

```bash
sed -n '1,20p' /root/pano-inpaint/server.env
sed -i 's|^QWEN_EDIT_PROMPT=.*|QWEN_EDIT_PROMPT="Remove the person. Reconstruct the background only. Do not add new people."|' /root/pano-inpaint/server.env
grep '^QWEN_EDIT_PROMPT=' /root/pano-inpaint/server.env
systemctl restart pano-lama
journalctl -u pano-lama -n 40 --no-pager
```

期望：不再出现 `command not found`，出现 `启动全景人像消除 Demo → http://0.0.0.0:7860`。然后打开 `http://10.2.143.129:7860`。

## 4. 加 Qwen-Edit（L20 46GB 可以开；仍用 NF4，先预下载）

### 4.1 环境

清华源经常没有新版 `diffusers` / `bitsandbytes`。仓库里 `setup.sh` 会回退官方 PyPI。一律用 **`.venv/bin/python`**，不要只 `source activate` 后又退回 conda `(base)`。

```bash
cd /root/qwen-edit-bench
export HF_ENDPOINT=https://hf-mirror.com
chmod +x setup.sh
./setup.sh
.venv/bin/python -c "import torch; from diffusers import QwenImageEditPlusPipeline; print(torch.__version__, torch.cuda.is_available())"
.venv/bin/python smoke_cpu.py
```

期望：`True`，以及 `smoke_cpu ok`。

若 `bitsandbytes` 仍失败：

```bash
cd /root/qwen-edit-bench
.venv/bin/python -m pip install bitsandbytes -i https://pypi.org/simple
```

### 4.2 先预下载权重（不要用网页第一次加载）

130 上 Gradio 等 1800s 超时，下载被杀掉，随后 GPU 掉总线。129 上 **必须先下完再点界面**。

```bash
cd /root/qwen-edit-bench
export HF_ENDPOINT=https://hf-mirror.com
export HF_HOME=/root/qwen-edit-bench/.cache/huggingface
.venv/bin/python - <<'PY'
from huggingface_hub import snapshot_download
p = snapshot_download("seochan99/Qwen-Image-Edit-2511-bnb-nf4")
print("ok", p)
PY
```

下完再：

```bash
cd /root/pano-inpaint
bash deploy_qwen_edit.sh
```

写入：

```
ENABLE_QWEN_EDIT=1
QWEN_EDIT_DEVICE=cuda
QWEN_EDIT_MAX_SIDE=768
QWEN_EDIT_BENCH=/root/qwen-edit-bench
QWEN_EDIT_DRY_RUN=0
WARMUP_QWEN=0
WARMUP_POWERPAINT=0
```

### 4.3 第一次点 Qwen

另开终端：

```bash
journalctl -u pano-lama -f
watch -n 1 nvidia-smi
```

日志应有 `worker ready`，**不应**再出现 1800s 超时。PowerPaint 与 Qwen 会互斥卸载，不要两个一起预热。

## 5. 目标 `server.env`（启用后）

路径：`/root/pano-inpaint/server.env`

```bash
HOST=0.0.0.0
PORT=7860
INBROWSER=0
LAMA_DEVICE=cuda
SAM_DEVICE=cuda
ENABLE_POWERPAINT=1
POWERPAINT_DEVICE=cuda
POWERPAINT_MAX_SIDE=768
IOPAINT_BENCH=/root/iopaint-bench
ENABLE_QWEN_EDIT=1
QWEN_EDIT_DEVICE=cuda
QWEN_EDIT_MAX_SIDE=768
QWEN_EDIT_MARGIN=256
QWEN_EDIT_BENCH=/root/qwen-edit-bench
QWEN_EDIT_DRY_RUN=0
MAX_INFER_SIDE=2048
PREVIEW_MAX_SIDE=960
HF_ENDPOINT=https://hf-mirror.com
WARMUP=1
WARMUP_QWEN=0
WARMUP_POWERPAINT=0
```

显存不够时：`ENABLE_QWEN_EDIT=0`，只开 LaMa + PowerPaint。

改完：

```bash
systemctl restart pano-lama
```

## 7. 不要做的

- 不要把 Qwen / 新 diffusers 装进 `/root/pano-inpaint/.venv` 或 `/root/iopaint-bench/.venv`

- 不要在 `nvidia-smi` 失败时继续点消除
